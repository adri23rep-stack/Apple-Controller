# Apple Controller

Control remoto nativo para Xuper TV Desktop (Windows). Se conecta por Wi‑Fi local con un código de emparejamiento.

Desarrollo inicial en la rama `feature/xuper-remote-v1`. No hay IPA ni release publicada todavía.

El programa Windows se mantiene en el repositorio separado [Xuper-Tv](https://github.com/adri23rep-stack/Xuper-Tv).
